# Content Batch Review

Date: YYYY-MM-DD
Reviewer: agent or human identity
Decision: accept / revise / reject

## Scope

List topic IDs, files changed, and the approved batch limit. Explain reused IDs and moves.

## Evidence

List source IDs, exact URLs, versions, dates consulted, and the claims they support.
Distinguish executed examples from conceptual examples. Name missing or conflicting evidence.

## Findings

Describe correctness, duplicate-topic checks, prerequisites, examples, trade-offs, and
version limitations. Record blocking findings. A formatting pass is not technical approval.

## Verification

Record exact validation, test, example, browser, and build commands and their results.

## Disposition

Accepted articles may enter docs/ within the user's approved scope. Rejected or revision
articles stay outside docs/. State remaining work and any required external authorization.
